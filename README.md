# Portfólio Pessoal — gustavolmx.github.io

Repositório oficial do meu portfólio web pessoal, desenvolvido para apresentar meus projetos, habilidades técnicas e certificações profissionais de forma limpa, responsiva e direta ao ponto.

 **Acesse o portfólio online:** [gustavolmx.github.io](https://gustavolmx.github.io)

---

##  Tecnologias Utilizadas

O projeto foi construído utilizando tecnologias web nativas, sem dependências de frameworks pesados, garantindo alta performance e carregamento rápido:

* **HTML5** — Estruturação semântica das páginas.
* **CSS3** — Estilização personalizada, design responsivo e identidade visual em tema escuro (*dark mode*).
* **JavaScript (ES6+)** — Interatividade da interface, manipulação do DOM e efeitos visuais.

---

## Seções da Aplicação
Início / Sobre: Apresentação profissional e objetivo de carreira em Análise de Dados.

Skills: Vitrine de tecnologias organizadas por categorias (Linguagens, Banco de Dados, Análise e Ferramentas).

Formação: Histórico acadêmico (ADS na UNISA e Técnico em Informática).

Projetos: Exibição dos principais desenvolvimentos práticos (Banco de Dados de Concessionária e Sistema de Assistência Técnica).

Contato: Links diretos para redes profissionais, e-mail e GitHub.
